  - "resources/js/**"
  - "resources/views/**"

Какие файлы затрагивает это правило:

| Путь к корневой папке | Название сущности          | Примечание                                                                                                                                                                                                     |
|-----------------------|----------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| /resources/css/*      | Стили                      | есть глобальные стили(папка global) - могут относиться к нескольким шаблонам страниц, есть персональные стили(папка views) - относятся к единственному шаблону страницы, app.css - набор дефолтных стилей      |
| /resources/js/*       | Скрипты JavaScript(JS)     | есть глобальные скрипты(папка global) - могут относиться к нескольким шаблонам страниц, есть персональные скрипты(папка views) - относятся к единственному шаблону страницы, app.js - набор дефолтных скриптов |
| /resources/views/*    | Шаблоны страниц(блэйдники) |                                                                                                                                                                                                                |


## Правила для вёрстки, фронт скриптов и стилей

1) Цвета только через CSS-переменные в `:root`, без хардкода в правилах
2) Все персональные стили для каждого шаблона страницы идут в соответствующем файле, inline-атрибутов **style=""** не писать
3) Все персональные скрипты для каждого шаблона страницы идут в соответствующем файле, в файле шаблона страницы скрипты через `<script></script>` не писать
4) Размеры в **rem**, **px** только для рамок, теней и скруглений
5) Кнопки одной высоты, скругление 8px, обязательное состояние **:hover**
6) Никаких CSS-фреймворков и внешних шрифтов - только системный шрифт
